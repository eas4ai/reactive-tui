# reactive-tui-macros

Procedural macros used by [`reactive-tui`](https://crates.io/crates/reactive-tui).

Applications normally depend on `reactive-tui`, which re-exports these macros.
The package is released separately so the main crate can resolve entirely from
crates.io.

Source and issue tracking live in the
[Reactive TUI repository](https://github.com/eas4ai/reactive-tui).
