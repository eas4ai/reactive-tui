The commitment requires preserving working APIs and escalating conflicting contracts.
If wrong:   Callers that supplied degrees to TransformProperty::Rotate through AnimatedProperty or rotate_animation will see different rotations and must convert their values to radians. The current API-010 repair remains uncommitted and is not accepted evidence.
Instead:    Choose degrees for TransformProperty::Rotate everywhere. That preserves the existing AnimatedProperty path and built-in spin, but changes the documented contract and direct TransformProperty::interpolate behavior for callers supplying radians.
